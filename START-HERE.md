## ⚡ Quick Start (5 Minutes)

Follow this simple checklist:

### 1. Create GitHub Account (if needed)
- Go to github.com
- Sign up or sign in
- Takes 2 minutes

### 2. Create Repository
- Click **+** icon → **New repository**
- Name: **yourusername.github.io**
  - Replace with your actual username
  - Example: sarah123.github.io
- Select **Public**
- Click **Create repository**

### 3. Upload Files
- Click **Add file** → **Upload files**
- Select: `blog-index.html` and `blog-posts.json`
- Write message: "Initial blog upload"
- Click **Commit changes**

### 4. Your Blog is Live!
- Visit: **https://yourusername.github.io**
- Wait 1-2 minutes for deployment
- 🎉 Your blog is live!

**That's it! You're done!**

## 💡 Popular Customizations

### Change Blog Title
Find this line in blog-index.html:
```html
<div class="logo">StreamBeat</div>
```
Change to your name or blog title.

### Change Colors
Find `:root` section in CSS:
```css
--accent-light: #ff4757;           /* Pink - change this */
--accent-secondary-light: #00b4db; /* Blue - change this */
```
Use color picker: https://htmlcolorcodes.com/

### Add Your Logo
Replace the `StreamBeat` text with your logo image:
```html
<img src="logo.png" alt="Logo" class="logo-img">
```

### Change Font
Replace Google Font in `<head>`:
```html
<link href="https://fonts.googleapis.com/css2?family=YOUR_FONT&display=swap">
```
