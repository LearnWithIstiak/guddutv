# ⚡ GitHub Deployment Quick Checklist

## 🎯 5-Minute Deployment Checklist

Use this checklist to deploy your blog in just 5 minutes!

---

## Step 1: GitHub Account & Repo (2 min)

- [ ] Go to **github.com**
- [ ] Sign up (if needed) or Sign in
- [ ] Click **+** icon → **New repository**
- [ ] Name: **yourusername.github.io**
  - Replace `yourusername` with your actual username
  - Example: `sarah123.github.io`
- [ ] Description: "StreamBeat - Live TV Streaming Blog"
- [ ] Select **Public**
- [ ] ✅ Click **Create repository**

**Your GitHub repo is ready!**

---

## Step 2: Upload Your Files (2 min)

- [ ] Click **Add file** → **Upload files**
- [ ] Select these files from your computer:
  - [ ] `blog-index.html`
  - [ ] `blog-posts.json`
- [ ] Add commit message: "Initial blog upload"
- [ ] ✅ Click **Commit changes**

**Your files are uploaded!**

---

## Step 3: GitHub Pages Auto-Enable (1 min)

- [ ] Wait 1-2 minutes
- [ ] Your site automatically deploys to:
  - **https://yourusername.github.io**
  - Replace `yourusername` with your actual username
- [ ] Visit your blog URL
- [ ] ✅ See your live blog!

**Your blog is live! 🎉**

---

## 🎯 That's It!

You're done! Your blog is now live on GitHub Pages.

---

## 📝 After Deployment

### To make changes:

1. Open your GitHub repository
2. Click the file you want to edit (e.g., `blog-index.html`)
3. Click the ✏️ **pencil icon**
4. Make changes
5. Scroll down → **Commit changes**
6. Add message (e.g., "Add new article")
7. ✅ Click **Commit**
8. Wait 1-2 minutes
9. Refresh your blog to see changes

### To add new articles:

1. Edit the `articles` array in `blog-index.html`, OR
2. Edit `blog-posts.json`
3. Commit changes
4. Wait 1-2 minutes
5. Refresh your blog

## ⚠️ Common Issues

| Issue | Solution |
|-------|----------|
| Blog not loading | Wait 2-3 min, hard refresh (Ctrl+F5) |
| 404 error | Check repo name has `.github.io` |
| Files not uploading | Try refreshing the page |
| Styling broken | Hard refresh (Ctrl+F5) or clear cache |
| Search not working | Hard refresh, check console (F12) |
